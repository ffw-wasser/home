- Bronze, Silber, Gold: Innenministerium Baden-Württemberg, Richtlinie Feuerwehr-Leistungsabzeichen, Neufassung 2026, Titelseite. https://www.lfs-bw.de/fileadmin/LFS-BW/themen/gesetze_vorschriften/leistungsabzeichen/dokumente/Richtlinie_Leistungsabzeichen.pdf
- Leistungsspange: Deutsche Jugendfeuerwehr, Ausbildungsfolien 2024, Titelfolie. https://jugendfeuerwehr.de/wp-content/uploads/2026/03/2024_Ausbildungsfolien_LSP.pdf
