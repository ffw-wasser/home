# Feuerwehr Wasser 3.0

Bereinigte, modular strukturierte Offline-Webanwendung.

## Struktur

- `js/core`: Konfiguration, Speicherung, Datenbank und allgemeine UI-Helfer
- `js/app`: Anwendungsstart und globale Navigation
- `js/features`: Anwesenheit, Statistik, Archiv, Berichte, Einsätze, Qualität und Taktik
- `js/vendor`: unveränderte Drittanbieter-Bibliotheken
- `css/core`: Grundgestaltung
- `css/components`: wiederverwendbare UI-Komponenten
- `css/features`: fachbezogene Gestaltung
- `css/layout`: responsive Layoutregeln einschließlich iOS
- `css/themes`: Dark Mode
- `css/maintenance`: geordnete Kompatibilitätsschichten in fester Ladereihenfolge
- `assets/templates`: Berichtsvorlagen

## Version 3.0

Historische, nicht mehr geladene Dateiversionen wurden entfernt. Aktive Hauptmodule besitzen stabile Dateinamen ohne Datumszusätze. Große Taktikgrafiken sind als WebP optimiert. Die bestätigten Funktions-, Layout-, Statistik-, Dark-Mode- und iOS-Korrekturen bleiben enthalten.
