# Nur für die Bereinigung früherer Testeinladungen

Der aktuelle Bedienablauf steht in [Kalender und Jahresplan](../KALENDER-BEDIENUNG.md).
Es gibt keine persönliche Einladungsanbindung, Kalenderadress-Registrierung oder
zusätzliche Freigabe der Rückmeldung mehr. Jeder hinterlegte GF kann direkt erinnern.

Die Dateien hier dienen ausschließlich dazu, eigene bereits angelegte Testkopien
zurückzuziehen. Sie sind keine Einrichtungsvoraussetzung für H₂O. Das bestehende
Google-Skript kann seine noch offenen Absageaufträge mit dem geschützten alten
Protokoll abschließen; alternativ ist die reduzierte `Code.gs` ohne Mailversand
verwendbar. Keine neuen Kalender, Adressen, Einladungen oder Kalenderantwortimporte.

Das Skript löscht nur eigene markierte Kopien mit passender Kennung und aktuellem
ETag, niemals den öffentlichen Quellkalender. Nach bestätigtem Abschluss entfernt
die reduzierte Vorlage ausschließlich ihren eigenen Trigger `h2oSyncInvitations`.
Der Anbieter kann Absagemeldungen anzeigen; manuell importierte Kopien werden
nicht zentral entfernt. Antworten und Berichte bleiben erhalten. Die geschützten
alten Tabellen und Abgleichrouten bleiben nur zur kompatiblen Bereinigung bestehen.
